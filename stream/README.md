# Stream API

## Stream API란?
  - Java는 객체지향 언어이지만 JDK8부터 Sttream API와 람다식, 함수형 인터페이스 등을 지원하면서 Java를 이용해 함수형 프로그래밍을 할 수 있는 API를 제공하고 있다.
  - 그 중에서 Stream API는 데이터를 추상화하고, 처리하는데 자주 사용되는 함수들을 정의해두었다.

## Stream API의 특징
  - 원본의 데이터를 변경하지 않는다.
  - 일회용이다.
  - 내부 반복으로 작업을 처리한다.
